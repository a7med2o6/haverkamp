# هافركامب الكويت — منصة الإدارة

منصة متكاملة لمركز هافركامب لحماية السيارات: موقع عام + لوحة تحكم داخلية
تشمل إدارة المحتوى، العملاء، الورشة، نقطة البيع، المخزون، والموارد البشرية.

**الموقع:** https://haverkampkw.com

---

## التقنيات

| الطبقة | التقنية |
|--------|---------|
| الإطار | Next.js 16 (App Router) + React 19 + TypeScript |
| التنسيق | Tailwind CSS 4 — عربي RTL مع وضع فاتح/داكن |
| قاعدة البيانات | PostgreSQL 17 + Prisma 7 (driver adapter) |
| المصادقة | Auth.js v5 — credentials + JWT + RBAC |
| العملة | الدينار الكويتي — 3 خانات عشرية (فلس) |

## التشغيل محلياً

```bash
npm install
```

**1. قاعدة البيانات** — عبر Docker:

```bash
docker compose up -d
```

أو Postgres مثبّت محلياً — أنشئ قاعدة ومستخدم باسم `haverkamp`.

**2. المتغيّرات:**

```bash
cp .env.example .env
```

ثم ولّد مفتاح المصادقة وضعه في `AUTH_SECRET`:

```bash
openssl rand -base64 32
```

**3. الجداول والبيانات الأولية:**

```bash
npm run db:migrate && npm run db:seed
```

**4. التشغيل:**

```bash
npm run dev
```

اللوحة على http://localhost:3000/dashboard

> **الحساب الافتراضي:** `admin@haverkampkw.com` / `Haverkamp@2026`
> غيّر كلمة المرور فوراً بعد أول دخول، أو مرّر `SEED_ADMIN_PASSWORD` قبل التعبئة.

بيانات تجريبية للاختبار (موظفون، منتجات، عملاء، حضور):

```bash
npm run db:seed:demo
```

## الأدوار والصلاحيات

الصلاحيات معرّفة في [`src/lib/rbac.ts`](src/lib/rbac.ts) بصيغة `module:action`.
الشريط الجانبي يُفلتر تلقائياً حسب دور المستخدم.

| الدور | الوصول |
|-------|--------|
| **OWNER / ADMIN** | كل شيء |
| **MANAGER** | العمليات والمبيعات والمخزون كاملة · المحتوى · اطّلاع على HR والتقارير |
| **HR** | الموارد البشرية كاملة · اطّلاع على التقارير |
| **ACCOUNTANT** | الفواتير والمخزون · اطّلاع على باقي الوحدات |
| **CASHIER** | نقطة البيع · اطّلاع على العملاء والمخزون |
| **TECHNICIAN** | أوامر الشغل · اطّلاع على العملاء |
| **RECEPTIONIST** | الحجوزات وأوامر الشغل والعملاء · اطّلاع على الفواتير |

## ملاحظات تقنية مهمة

**التواريخ بدون وقت.** حقول `@db.Date` (الحضور، الإجازات) تُخزَّن عند منتصف
ليل UTC. استخدم `todayDateOnly()` و `dateOnlyFromInput()` و `formatDateOnly()`
من `lib/utils` — الاعتماد على `setHours(0,0,0,0)` المحلي يُنقص يوماً كاملاً
في الكويت (UTC+3).

**الثوابت المشتركة.** لا تُصدِّر قيماً من ملف يبدأ بـ `'use client'` ثم
تستوردها في مكوّن خادم — تصل كمرجع للعميل لا كقيمة. ضعها في `lib/constants.ts`
أو `lib/utils.ts`.

**المبالغ.** كل الحقول المالية `Decimal(12,3)` أو `Decimal(14,3)`. استخدم
`toNumber()` قبل الحساب في المكوّنات، و `formatKWD()` للعرض.

**رسائل الأخطاء.** قواعد العمل تُبلَّغ بـ `throw new AppError('رسالة للمستخدم')`
من `lib/action-utils`. أي `Error` عادي يُعتبر خطأً غير متوقع وتُعرض للمستخدم
رسالة عامة بدلاً منه حتى لا تتسرّب تفاصيل داخلية — فاستخدم `AppError` دائماً
للرفض المقصود، وإلا لن يرى المستخدم سبب الرفض.

**قواعد الإجازات.** الأنواع في الإعداد `hr.unpaidLeaveTypes` (بدون راتب
افتراضياً) تُخصم من المسيّر بأيامها الفعلية داخل الشهر، بلا مضاعفة لأنها
إجازة معتمدة لا غياب. رصيد الإجازة السنوية يحجز الطلبات **المعلّقة** أيضاً
لا المعتمدة فقط.

**قواعد الرواتب.** الغياب في الأيام المحدّدة في الإعداد `hr.doubleDeductionDays`
(الخميس والسبت افتراضياً) يُخصم بيومين لأنهما يحيطان بعطلة الجمعة. يُعدَّل الإعداد
من قاعدة البيانات دون لمس الكود. إعادة توليد المسيّر تُبقي البنود اليدوية
(`isManual`) وتحذف أقساط السلف الخاصة بالمسيّر ثم تعيد احتسابها — لذلك لا
تتضاعف عند التوليد المتكرر.

**قوائم القيم (enums).** لا تكرّر قيم enum بريزما يدوياً داخل مخططات zod —
تنحرف بصمت عند إضافة قيمة جديدة فيفشل التحقق دون رسالة واضحة. استوردها من
`@/generated/prisma/enums` واستخدم `z.enum(DocumentType)` مباشرة.

**المخزون.** يُحدَّث داخل `$transaction` دائماً (البيع، الحركات اليدوية) —
لتفادي اختلال الرصيد عند عمليتين متزامنتين. الفاتورة المعلّقة (`DRAFT`)
لا تخصم مخزوناً؛ يُخصم عند أول تحصيل عليها.

## النشر على VPS

```bash
# على السيرفر
git clone https://github.com/a7med2o6/haverkamp.git && cd haverkamp
cp .env.example .env      # املأ القيم — DATABASE_URL و AUTH_SECRET و AUTH_URL
docker compose up -d      # قاعدة البيانات
npm ci
npm run db:deploy         # تطبيق الهجرات
npm run db:seed           # أول مرة فقط
npm run build
npm run start             # أو عبر pm2 / systemd
```

ثم ضع nginx أو Caddy أمام المنفذ 3000 مع شهادة TLS، ووجّه `haverkampkw.com`
إلى السيرفر.

**قبل النشر:**
- غيّر `POSTGRES_PASSWORD` و `AUTH_SECRET` عن القيم الافتراضية
- اضبط `AUTH_URL` على الدومين الفعلي بـ https
- فعّل نسخاً احتياطياً دورياً لقاعدة البيانات (`pg_dump`)

## حالة التنفيذ

**مكتمل ويعمل:**

- الأساس: قاعدة بيانات، مصادقة، صلاحيات، هيكل اللوحة
- العملاء والسيارات — سجل كامل بترقيم تلقائي وبحث
- الحجوزات — بتصفيات وتحويل إلى أمر شغل
- أوامر الشغل — دورة حياة كاملة، بنود، فنيون، كفالات، فوترة
- نقطة البيع — واجهة لمسية، إضافة فورية بالباركود، دفع مقسّم على عدة
  طرق، تعليق واسترجاع الفواتير، ورديات صندوق
- الفواتير — قائمة وصفحة قابلة للطباعة
- المنتجات والمخزون — حركات ذرّية وتنبيهات إعادة الطلب
- الموارد البشرية — بروفايل موظف كامل (بيانات، مالية، تواريخ حساسة،
  وثائق برفع ملفات، سجل إجازات)، حضور، إجازات، تقييم
- الرواتب — مسيّر شهري يحتسب الأساسي والبدلات والإضافي، ويخصم الغياب
  وأقساط السلف، مع بنود يدوية (مكافآت/جزاءات) وقسيمة قابلة للطباعة
- السلف — أقساط شهرية تُخصم تلقائياً من المسيّر مع تتبّع المتبقي
- تقرير حضور شهري لكل موظف
- تنبيه الإقامات: لوحة التحكم تعرض الإقامات وأذونات العمل المنتهية
  أو التي تنتهي خلال 15 يوم، وتصفية مطابقة في قائمة الموظفين
- المستخدمون والصلاحيات

**الموقع العام — نقل تدريجي:**

الصفحة الرئيسية مبنية في Next.js: `/` بالعربية و `/en` بالإنجليزية،
وكلاهما يُصيَّر على الخادم من قاعدة البيانات (الخدمات والترجمات
والإعدادات). التصميم يستعير `css/styles.css` من الموقع الثابت بدل
تفريعه، وسكربتات الحركة تُحمَّل من `public/js/`.

صفحات الخدمات المنقولة إلى Next: **الجام، البوليش، الصبغ** — بقالب
واحد يعرض القسم فقط إن وُجد محتواه، مع الحفاظ على امتداد `.html` في
الروابط لأنها مفهرسة به. الباقي (التظليل، حماية البدي، الغسيل) ما زال
ثابتاً لأن له أقساماً خاصة (مستويات العزل، الماركات، الباقات) لم تُبنَ بعد.

الصفحات الثابتة ينسخها
`scripts/sync-legacy.mjs` من `legacy/` إلى `public/` عند كل
`npm run dev` أو `npm run build`. النسخ داخل `public/` متجاهَلة من git —
المصدر الوحيد هو `legacy/`.

تذييل الصفحة الرئيسية يحوي مدخل **دخول الموظفين** إلى `/login`
بـ `rel="nofollow"` حتى لا تفهرسه محركات البحث.

**متبقٍّ:**

- بناء الموقع العام بـ Next.js — الترجمات (768 مفتاح) والخدمات مستوردة
  بالفعل في قاعدة البيانات وجاهزة للاستخدام
- لوحة إدارة المحتوى (CMS) — الجداول موجودة، الواجهات ناقصة
- صفحات: السيارات، الكفالات، حركة المخزون، المورّدون، أوامر الشراء،
  التقارير، الإعدادات العامة
- رفع الصور من اللوحة
- إشعارات واتساب للحجوزات والكفالات

الروابط غير المبنية مُعلَّمة بـ `soon: true` في
[`nav-config.ts`](src/components/dashboard/nav-config.ts) ومخفيّة من القائمة.
